# Контент-план в Telegram: пошаговая инструкция

Что получится: в чате с вашим личным ботом внизу слева кнопка «План». Она открывает приложение (План, Календарь, Идеи, Снято, Бренд). Любое сообщение, которое вы напишете боту, попадает в «Идеи».

Время: примерно 30–40 минут вашей работы. Бесплатно: Telegram и тарифа Cloudflare Free хватает с большим запасом.

## Шаг 1. Создайте бота (телефон, 5 минут)

1. В Telegram найдите **@BotFather**. Рядом с именем должна стоять синяя галочка. Других ботов с похожим именем не используйте.
2. Нажмите «Start» и отправьте `/newbot`.
3. Он спросит **имя бота**, оно показывается в чате. Например: `Контент-план Ульяны`.
4. Потом спросит **username**. Он должен заканчиваться на `bot` и быть свободным. Например: `ulya_plan_bot`. Если занято, добавьте цифры.
5. BotFather пришлёт **токен**: длинную строку вида `1234567890:AA...`. Это пароль от бота.

Токен:
- не отправляйте мне и никому в чат;
- не вставляйте в файлы репозитория;
- сохраните в заметках или менеджере паролей. Он понадобится на шаге 5.

Если токен случайно попал на чужие глаза: BotFather, `/revoke`, выберите бота. Старый токен перестанет работать, придёт новый.

## Шаг 2. Создайте аккаунт Cloudflare (почта, 5 минут)

1. Откройте https://dash.cloudflare.com/sign-up и зарегистрируйтесь. Подтвердите почту.
2. Карта не нужна. Выбирайте бесплатный тариф (Free).
3. Запомните почту и пароль. Больше пока ничего не делайте.

Здесь будут жить приложение, бот и база с вашими темами.

## Шаг 3. Пришлите мне username бота

Только username, например `ulya_plan_bot`. Токен не присылайте.

## Шаг 4. Код (делаю я)

Я напишу:
- бота: принимает сообщения, кладёт их в «Идеи», отвечает «записала»;
- небольшой сервер: хранит темы, идеи и отметки в базе;
- подключение приложения к серверу (сейчас оно хранит данные только в браузере);
- защиту: сервер проверяет подпись Telegram и пускает только вас;
- команду `/export`, чтобы получить резервную копию файлом.

Проверю локально и напишу, что готово.

## Шаг 5. Выложите на хостинг (компьютер, 15 минут)

Нужен Mac или ПК. Если компьютера нет или терминал пугает, скажите: я подготовлю вариант с подключением репозитория через сайт Cloudflare, без команд.

1. Установите Node.js (версия LTS): https://nodejs.org
2. Откройте Терминал (Mac: Cmd+Пробел, «Терминал»; Windows: «PowerShell»).
3. Скачайте проект и перейдите в папку бота (точные команды я пришлю вместе с кодом).
4. Выполните по очереди:

```bash
npx wrangler login
npx wrangler d1 create ulya-plan
npx wrangler d1 execute ulya-plan --remote --file=schema.sql
npx wrangler secret put BOT_TOKEN
npx wrangler deploy
```

- `login` откроет браузер, нажмите «Allow».
- После `d1 create` в ответе будет строка `database_id`. Её нужно вставить в файл `wrangler.toml` (покажу, куда).
- `secret put BOT_TOKEN`: терминал попросит вставить токен. Он не отображается на экране, это нормально. Вставьте, нажмите Enter.
- После `deploy` терминал напишет адрес вида `https://ulya-plan.<ваше-имя>.workers.dev`. Скопируйте его.

## Шаг 6. Подключите бота к серверу

1. Вставьте в адресную строку браузера, подставив токен и адрес из шага 5:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=<АДРЕС>/telegram
```

   Ответ `{"ok":true,...}` значит, что всё подключено. Ссылку с токеном никому не показывайте.
2. Откройте чат с ботом и нажмите «Start». Бот ответит вашим Telegram ID, это число.
3. Вернитесь в терминал:

```bash
npx wrangler secret put ALLOWED_USER_ID
```

   Вставьте число. Теперь бот и приложение работают только для вас, остальным бот ответит «это личный бот».

## Шаг 7. Кнопка «План» в чате (телефон)

1. BotFather, `/mybots`, выберите вашего бота.
2. Bot Settings, Menu Button, Configure menu button.
3. Отправьте адрес из шага 5 и название кнопки: `План`.

## Шаг 8. Проверка

1. Откройте чат с ботом, нажмите «План». Приложение должно открыться на весь экран в тёмном оформлении.
2. Добавьте тему, отметьте её снятой, перенесите дату.
3. Закройте приложение и откройте снова: записи на месте.
4. Напишите боту «тест идеи». Откройте «Идеи»: сообщение там.
5. Отправьте `/export`: бот пришлёт файл с копией.

## Если что-то не так

- **Кнопки «План» нет:** проверьте шаг 7, адрес должен начинаться с `https://`. Закройте и откройте чат.
- **Бот молчит:** откройте `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo`. Если в `url` пусто, повторите шаг 6. Если есть `last_error_message`, пришлите мне его текст без токена.
- **Приложение открывается, но пустое или пишет об ошибке доступа:** не записан `ALLOWED_USER_ID` или записан чужой ID. Повторите шаг 6.3.
- **Сообщение «Unauthorized» или «Not Found» при `wrangler`:** повторите `npx wrangler login`.

## Безопасность и резервные копии

- Токен хранится только в секретах Cloudflare. Если подозреваете утечку: `/revoke` и повторить `secret put BOT_TOKEN`.
- Данные видит только ваш Telegram-аккаунт. Если сменится аккаунт, поменяйте `ALLOWED_USER_ID`.
- Адрес приложения технически публичный. Темы и идеи защищены проверкой Telegram. Вкладку «Бренд» с брендбуком и фотографиями я тоже отдам только после этой проверки, чтобы по ссылке посторонний их не увидел.
- Раз в неделю присылайте боту `/export` и сохраняйте файл. Это страховка на случай ошибки.
- Cloudflare Free хватает с запасом для одного человека: десятки тысяч запросов в день и гигабайт базы.
