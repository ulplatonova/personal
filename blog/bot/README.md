# Бот и приложение «Контент-план»

Cloudflare Worker: бот @ulyascontentplan_bot, API и приложение (`public/index.html`). Запуск пошагово: `../app/INSTRUCTION.md`.

- `src/worker.js`: сервер (вебхук бота, API, проверка подписи Telegram, `/setup`).
- `public/index.html`: приложение. Источник правды теперь здесь; `../app/index.html` это прежний визуальный прототип.
- `public/private/`: вкладка «Бренд» и фото. Выдаётся только после проверки Telegram, напрямую недоступна.
- `schema.sql`: две таблицы (`items`, `ideas`), записи хранятся как JSON.
- `wrangler.toml`: настройки; сюда вставляется `database_id`.

Секреты (не в репозитории): `BOT_TOKEN`, `ALLOWED_USER_ID`.

Локально проверено: подпись initData (чужой пользователь, подделка, просрочка), сохранение и чтение, идея от бота, закрытые файлы, загрузка 20 фото, подтягивание новой идеи при возврате в приложение. Не проверено на настоящем Telegram и Cloudflare.
