# Вставки со звуками

Основа — разбор двух референсов (11.11.2026): ролик про «еду для красоты» и ролик «подарки на Новый год». Монтаж субтитров и наклеек по-прежнему по скиллу `belo-rozovye-subtitry`; этот скилл добавляет звук и новые типы вставок.

## Что делают в референсах (измерено)
- **Звук на каждую вставку.** Появление картинки и короткий звук совпадают с точностью ±0,1 с. Два типа:
  - мягкий «вжух»/шелест 70–170 мс, яркий (центр спектра ~4–5 кГц) — спокойный lifestyle;
  - короткий щелчок/«поп» 10–50 мс (центр ~2–3 кГц) — бойкий ритм, много вставок.
  Звук тише голоса, голос всегда разборчив.
- **Вставки фото:** 1–3 картинки сразу, внахлёст, иногда с лёгким поворотом; появляются «прыжком». Держатся, пока говорят о предмете.
- **Заголовок темы** у каждого блока (крупно, над головой): «сардины», «чечевица», «зелень для кишечника».
- **Хук-коллаж:** вокруг лица много вырезанных предметов + крупный заголовок.
- **Скриншот профиля бренда** (шапка Instagram) сверху, когда бренд называют.
- **Плашка-отметка**: тёмная капсула, круглая аватарка, ник и имя — в конце, когда отмечают человека.
- **Призыв «сохрани»** текстом в первые 4–6 секунд.
- Постоянный мудборд-коллаж внизу (в ролике про еду) — фирменная рамка ролика.

## Инструменты
- `sfx/` — звуки: `pop_short.wav` (короткий поп 45 мс, по умолчанию, −18 дБ), `pop.wav` (поп), `click.wav` (щелчок), `whoosh.wav` (вжух), `sparkle.wav` (динь-динь). Синтезированы, без авторских прав. Если Ульяна пришлёт свои звуки — используем их (путь к wav прямо в `sfx`).
- `scripts/add_sfx.py in.mp4 cues.json out.mp4` — накладывает звуки по таймингу; видео копируется без перекодирования; голос выравнивается до −14 LUFS **до** смешивания; шумоподавления нет.
  `cues.json`: `[{"t": 2.6, "sfx": "pop", "db": -10}, ...]`. Громкость: поп −10 дБ, щелчок −14, вжух −12, динь −14.
- `scripts/make_pill.py avatar.jpg "ник" "Имя" pill.png --scale 1.3` — плашка-отметка. На видео: `overlay` с выездом слева за 0,25 с, y≈1240 (над субтитрами), звук `sparkle` или `pop`.
- Вставки-картинки и наклейки — через `render_reel.py` из скилла `belo-rozovye-subtitry` (список `STICK`): фото-карточки, вырезанные предметы, скриншоты профилей. Тайминги звуков берутся из тех же моментов появления (`t0` каждой вставки; цена — +0,15 с).

## Правила по умолчанию (стиль Ульяны)
- Звук на **каждое** появление вставки, а не через раз; на цену после наклейки — тише (щелчок).
- Для спокойных роликов — `pop`/`whoosh`; щелчки — если вставок много и ритм быстрый.
- Наклейки средств — по правилам бело-розовых субтитров (верхние углы, не на лице, спокойная анимация). «Прыгающую» анимацию из референсов включать только если Ульяна попросит.
- Сначала превью 1080p со звуком — слушает Ульяна; 4K только после «да».
