# Контент-план в Telegram: пошаговая инструкция

Что получится: в чате с ботом **@ulyascontentplan_bot** слева от поля ввода кнопка «План». Она открывает приложение (План, Календарь, Идеи, Снято, Бренд). Любое сообщение, которое вы напишете боту, попадает в «Идеи». Команда `/export` присылает резервную копию файлом.

Время: около 30–40 минут. Стоимость: 0 ₽ (бесплатные тарифы Telegram и Cloudflare).

Код готов и лежит в папке `blog/bot/`. Я проверила его локально на тестовых данных. С настоящим Telegram и вашим Cloudflare его ещё никто не запускал, поэтому при первом запуске что-то может потребовать правки. В конце есть раздел «Если что-то не так», и можно присылать мне текст ошибки (без токена).

---

## Что понадобится

- Телефон с Telegram (шаги 1, 3, 8).
- Компьютер Mac или Windows (шаги 2, 4–7). Если терминал пугает, скажите мне: подготовлю вариант без команд, через сайт Cloudflare.
- Почта для Cloudflare.

## Шаг 1. Создайте бота у BotFather (телефон, 5 минут)

Имя для бота уже выбрано: `ulyascontentplan_bot`.

1. В Telegram найдите **@BotFather** (рядом синяя галочка). Нажмите «Start».
2. Отправьте `/newbot`.
3. Имя бота, которое видно в чате: например, `Контент-план Ульяны`.
4. Username: `ulyascontentplan_bot`. Если BotFather скажет, что занято, добавьте цифру и пришлите мне новый.
5. Он пришлёт **токен**, длинную строку вида `1234567890:AA...`. Это пароль от бота.

Токен:
- не отправляйте мне и никому в чат;
- не вставляйте в файлы проекта;
- сохраните в менеджере паролей или заметках, он понадобится на шаге 5.

Если токен попал на чужие глаза: BotFather, `/revoke`, выберите бота. Старый перестанет работать, придёт новый.

## Шаг 2. Аккаунт Cloudflare и Node.js (компьютер, 10 минут)

1. https://dash.cloudflare.com/sign-up. Зарегистрируйтесь, подтвердите почту. Карта не нужна, тариф Free.
2. Установите **Node.js** версии LTS: https://nodejs.org (кнопка «LTS», далее «Далее» до конца).
3. Скачайте проект: откройте репозиторий `ulplatonova/personal` на GitHub, выберите ветку `claude/epic-wright-i16gdb`, нажмите «Code», затем «Download ZIP». Распакуйте архив.
4. Откройте Терминал в папке `blog/bot` внутри распакованного проекта:
   - **Mac:** Терминал, напишите `cd ` (с пробелом), перетащите папку `bot` в окно терминала, Enter.
   - **Windows:** в проводнике откройте папку `bot`, нажмите на адресную строку, напишите `powershell`, Enter.
5. Выполните:

```bash
npm install
npx wrangler login
```

   `login` откроет браузер. Нажмите «Allow».

## Шаг 3. База данных

В том же терминале:

```bash
npx wrangler d1 create ulya-plan
```

В ответе будет строка `database_id = "..."` (набор букв и цифр с дефисами). Откройте файл `wrangler.toml` из папки `bot` в любом текстовом редакторе (Блокнот, TextEdit) и замените надпись `ВСТАВЬТЕ_СЮДА_database_id_ИЗ_ОТВЕТА_wrangler_d1_create` на этот идентификатор, оставив кавычки. Сохраните.

Затем создайте таблицы:

```bash
npx wrangler d1 execute ulya-plan --remote --file=schema.sql
```

Если спросит подтверждение, ответьте `y`.

## Шаг 4. Выложите приложение

```bash
npx wrangler deploy
```

Если wrangler предложит выбрать имя для вашего адреса на `workers.dev`, придумайте любое (латиницей) и подтвердите.

В конце терминал напишет адрес вида `https://ulya-plan.ваше-имя.workers.dev`. **Скопируйте его.**

## Шаг 5. Токен бота

```bash
npx wrangler secret put BOT_TOKEN
```

Терминал попросит значение. Вставьте токен из шага 1 и нажмите Enter. Символы на экране не показываются, это нормально.

## Шаг 6. Подключите бота и кнопку «План»

Откройте в браузере (подставив свой адрес из шага 4):

```
https://ваш-адрес.workers.dev/setup
```

Должно появиться «Готово.» и три строки «ок» (вебхук, кнопка «План», команды). Страницу можно открывать повторно, это безопасно.

## Шаг 7. Закройте доступ только для себя

1. В Telegram откройте чат с вашим ботом и нажмите «Start». Бот ответит: «Ваш Telegram ID: 123456789». Скопируйте число.
2. В терминале:

```bash
npx wrangler secret put ALLOWED_USER_ID
```

   Вставьте число, Enter.

С этого момента бот и приложение работают только для вас. Остальным бот отвечает «Это личный бот».

## Шаг 8. Проверка (телефон)

1. Напишите боту `/start`. Он ответит приветствием, слева от поля ввода появится кнопка «План».
2. Нажмите «План». Откроется приложение в тёмном оформлении, пустое.
3. Нажмите «+», добавьте тему с датой, отметьте её снятой, перенесите дату. Откройте «Календарь».
4. Закройте приложение и откройте снова: записи на месте.
5. Напишите боту «тест идеи» и вернитесь в приложение: идея в «Идеях».
6. Откройте «Бренд»: должны загрузиться текст и фотографии.
7. Отправьте боту `/export`: придёт файл с копией.

Если всё работает, готово.

## Если что-то не так

- **Приложение пишет «Откройте из Telegram».** Вы открыли адрес в обычном браузере. Открывайте только кнопкой «План» в чате.
- **Приложение пишет «Нет доступа».** Не записан `ALLOWED_USER_ID` или записан не тот номер. Повторите шаг 7.
- **Кнопки «План» нет.** Откройте адрес `/setup` ещё раз (шаг 6). Закройте и снова откройте чат.
- **Бот молчит.** Проверьте в браузере (подставьте токен):
  `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo`. Если `url` пустой, повторите шаг 6. Если есть `last_error_message`, пришлите мне его текст, токен не присылайте.
- **`/setup` пишет «Сначала запишите BOT_TOKEN».** Повторите шаг 5.
- **Ошибки в терминале про вход (Unauthorized, Not logged in).** Повторите `npx wrangler login`.
- **`d1 execute` пишет, что не находит базу.** Проверьте, что `database_id` в `wrangler.toml` вставлен без пробелов и в кавычках, затем повторите шаг 3.
- **Фото во вкладке «Бренд» не показываются.** Закройте приложение и откройте снова. Если не помогло, пришлите скриншот.

## Безопасность и резервные копии

- Токен хранится только в секретах Cloudflare. Если подозреваете утечку: `/revoke` у BotFather и повторите шаг 5.
- Данные видит только ваш Telegram-аккаунт: сервер проверяет подпись Telegram и ваш номер. Если сменится аккаунт, перезапишите `ALLOWED_USER_ID`.
- Адрес приложения публичный, но посторонний увидит только пустую страницу. Темы, идеи, брендбук и фотографии выдаются только после проверки Telegram.
- Раз в неделю присылайте боту `/export` и сохраняйте файл. Это страховка на случай ошибки.
- Бесплатного тарифа Cloudflare хватает с большим запасом для одного человека.

## Как обновлять приложение

Когда я меняю код, вы скачиваете новую версию проекта и в папке `blog/bot` выполняете одну команду: `npx wrangler deploy`. Данные не пропадают, они в базе.
